Игровой цикл: Безопасная Зарядка
Фиджитал-приложение для детей 6-11 лет: гимнастика + безопасность
Фаза 1: Вход и выбор
1Ребенок открывает веб-приложение (мобильное или десктоп)
2Выбор аватара / вход как гость
3Выбор сезона (весна / лето / осень / зима) — определяется автоматически или вручную
↓
Фаза 2: Утренняя гимнастика (фиджитал)
4Приложение показывает анимацию упражнения (название + счётчик)
5Ребенок выполняет упражнение в реальном мире (прыжки, наклоны, махи)
6Таймер отсчитывает время выполнения (15-30 сек)
7По завершении — зелёная галочка на экране
8Переход к следующему упражнению (5-7 упражнений в комплексе)
↓
Фаза 3: Квиз по безопасности
9Выбор локации (компьютер / телефон / дом / улица / школа / парк / лес)
10Приложение задаёт вопрос по безопасности (сезон + локация)
11Ребенок выбирает ответ из 3-4 вариантов
12Правильный ответ — зелёная галочка + очки
13Неправильный ответ — вибрация устройства + подсветка правильного ответа
14Краткое объяснение правильного ответа (обучающий момент)
↓
Фаза 4: Награды и прогресс
15Начисление звёзд / монет за выполнение упражнений и правильные ответы
16Разблокировка новых аватаров / комплексов упражнений
17Отображение прогресс-бара (сколько дней подряд)
↓
Фаза 5: Отчёт для родителей
18Родитель открывает дашборд (PIN-код)
19Статистика: упражнения выполнены, вопросы по безопасности, правильные/неправильные
20Рекомендации: на какие темы обратить внимание
