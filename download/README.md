Безопасная Зарядка

Приложение для проведения безопасных зарядок под сезоны, викторинами и обратной связью.

Возможности

Визуальная и тактильная обратная связь: конфетти при отличном результате, вибрация при ошибке, пульсирующий красный таймер при нехватке времени — всё это создаёт эмоциональную вовлечённость.
 По сезонам: комплексы упражнений и правила безопасности подстраиваются под время года.
Викторины: вопросы для проверки знаний с фильтрацией по типам.

Требования

Git (https://git-scm.com) для клонирования репозитория
Bun (https://bun.sh) как пакетный менеджер и runtime

Установка и запуск

1. Клонировать репозиторий
git clone <url-репозитория>
cd my-project

2. Установить зависимости
bun install

3. Запустить в режиме разработки
bun run dev

Приложение будет доступно по адресу: http://localhost:3000

Сборка для продакшена

Сборка оптимизированной версии
bun run build

Запуск продакшен-сервера
bun run start

Доступные скрипты

Скрипт | Команда | Описание
dev | bun run dev | Запуск dev-сервера на порту 3000 с логированием
build | bun run build | Сборка + копирование static и public в standalone
start | bun run start | Запуск продакшен-сервера (Node/Bun)
lint | bun run lint | Проверка кода ESLint
